# AI レビューフロー対応指示書

本指示書は、本 AI レビューシステム（`ame-ai-review-system`）の導入リポジトリ用の開発ルールです。**開発者（人間）や AI エージェント（Claude
Code 等）が AI レビューに正しく対応するための手順とルール**を定めます。

AI レビューが有効なプロジェクトで作業する際は、本ドキュメントを必ず参照し、指示に従ってフローを完了させてください。

---

## AI レビューの全体的な流れ

AI レビュアーとのやり取りは、プルリクエスト (PR) のスレッド上で行われます。

```text
[PR 作成 / プッシュ]
       │
       ▼
 1. AI が自動で一次レビューを実施し、問題箇所にインラインコメントを投稿
       │
       ├──────────────────────────────┐
       ▼                              ▼
 [指摘への対応 (コード修正)]     [指摘が不要な場合 (ディスカッション)]
       │                              │
       ├──────────────────────────────┘
       ▼
 2. 開発者がコメントスレッドに `@<レビュアー名> 対応内容` で返信
       │
       ▼
 3. 返信を検知した AI が最新 diff を再読込し、LGTM 判定
       │
       ├─── (修正が不十分な場合) ───► 再度インライン指摘コメント (1. へ戻る)
       │
       ▼ (修正完了を確認した場合)
 4. AI が「LGTM ✅ Resolve してください。」と返信
       │
       ▼
 5. 開発者（人間または AI）がスレッドを 「Resolve」 に変更して終了
```

---

## 開発対応フロー（必須ルール）

PR を作成・更新した後は、**未解決のレビューコメントがゼロになるまで**
以下のサイクルを実行してください。

### Step 1: インライン指摘コメントの確認

AI レビュアー（Gitea の設定で指定したアカウント名、デフォルトは`ame-ai-reviewer`）から PR にインラインレビューコメントが届く。

- 指摘には重大度（`CRITICAL` / `HIGH` / `MIDDLE` / `LOW`）のアイコンが付与されている。

### Step 2: コード修正とプッシュ

1. 指摘事項に対応する修正をコードに加える。
2. ローカルで Linter / Formatter / テストを実行してパスすることを確認する。
3. 修正をコミットして PR ブランチへプッシュする。

### Step 3: 指摘スレッドへの返信

修正が完了したら、対象のレビューコメントスレッドに対し、**必ず AI レビュアーへの `@メンション`
を含めて対応内容を返信する**。

- 例: `@ame-ai-reviewer 指摘された境界値のバリデーション処理を追加しました。`
- **重要**: メンションを含めないと、AI の自動返信判定（Step 4）がトリガーされない。
- 指摘が不要であると判断した場合は、その旨の理由を書いてメンション付きで返信する。

### Step 4: AI による再評価と LGTM 返信の確認

プッシュと返信を検知すると、AI レビュアーが自動的に最新の diff を検証し、スレッドに返信する。

- **修正が完了している場合**: AI が `対応確認しました。LGTM ✅ Resolve してください。` と返信する。
- **修正が不十分な場合**: 不足点や追加の指摘が返信される。この場合は Step 2 に戻って再修正する。

### Step 5: スレッドの Resolve

AI から `LGTM` の返信が届いたスレッドは、開発者が **「Resolve（解決済み）」** に変更する。

- すべてのスレッドが Resolve された時点で、AI レビューフローは完了となる。

## AI エージェント（Claude Code 等）向けの自動化ルール

AI 開発アシスタント（Claude
Code 等）がこのプロジェクトで PR 修正作業を行う場合は、以下のルールを厳守してください。

1. **未解決スレッドの自動走査**: PR 修正タスクの開始時に Gitea/GitHub
   API を用いること。AIレビュアー（デフォルト：`ame-ai-reviewer`）のインラインコメントを走査し、未解決スレッドを特定すること。
2. **修正から返信までの一括処理**: コードを修正した後は、速やかに Gitea
   API で返信メッセージを投稿すること。
   - 返信 API: `POST /api/v1/repos/{owner}/{repo}/pulls/{index}/comments/{id}/replies`
   - 本文には必ず AIレビュアー（デフォルト：`@ame-ai-reviewer`）へのメンションを含める。
3. **LGTM 待機と Resolve 処理**: AI レビュアーからの `LGTM`
   返信が API 経由で取得できるまで待機し、確認後にスレッドを Resolve（解決）に変更すること。
   - Resolve API: `POST /api/v1/repos/{owner}/{repo}/pulls/comments/{id}/resolve`
